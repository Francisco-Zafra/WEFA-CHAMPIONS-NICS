# Presentación

Presentación corta de la app para compartir con el grupo: las funcionalidades clave, una por diapositiva, y los detalles secundarios al final.

- **[WEFA-Champions-NICS.pdf](WEFA-Champions-NICS.pdf):** para mandar o ver directamente en GitHub.
- **[index.html](index.html):** la misma presentación en HTML. Ábrela en el navegador y pasa de diapositiva con las flechas, la barra espaciadora o un clic. Cada diapositiva lleva notas para presentarla en voz alta (en un `<aside>` oculto).
- **`img/`:** capturas de la app (versión 3.1.0) hechas con datos de prueba en los emuladores, no con partidos reales.

Las diapositivas miden 1920×1080 y usan las tipografías de la app (Bebas Neue y Geist, desde Google Fonts).
